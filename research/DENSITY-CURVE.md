**The quantity that decides everything.** After the parity split, Erdős 273 asks for TWO DISJOINT distinct-moduli covering systems drawn from `H = {(p−1)/2 : p prime ≥ 5}`. A distinct-moduli covering system of ℤ has `Σ 1/m > 1` **strictly** (≥ 1 by density; equality is an exact cover, impossible for ≥ 2 distinct moduli by Mirsky–Newman). So a witness with `lcm | 2N` requires

> **`S(N) = Σ_{h ∈ H, h | N} 1/h  >  NEED = 2`**

`S ≤ 2` is therefore **UNSAT by density alone — no solver is run, and none is needed.**

## The ceiling — why the window never opens wide

**Read this against the only known construction.** Selfridge's half — the `p ≥ 3` example's legal `p ≥ 5` part — runs at `Σ 1/h = 1.5556` over 11 moduli, i.e. **55.6 % slack for ONE half**. If a second, disjoint half needed comparable room, the pool would have to carry `S ≈ 3.1`. The table above says `S ≈ 2.98` at `N ≈ 4·10²¹`, and the CNF at that N is beyond astronomical. **So `S ≈ 3.1` is not reachable at any N, ever, by this route.**

> ### THE VERDICT THIS CURVE FORCES

> A witness for Erdős 273, if one exists, **cannot** resemble Selfridge's construction. It must be **far more reciprocal-efficient than any known covering system**: two disjoint halves living inside a pool with only **4–13 % total slack**, where the only comparable object in the literature uses 56 % for one half. The SAT window (`27,720 ≤ N ≤ 360,360`, slack 4.4–10.6 %) is exactly where such an object would have to live, which is why every rung in it gets thrown at the solvers — but the curve is the honest statement of the odds, and of why 1980–2026 produced nothing.
